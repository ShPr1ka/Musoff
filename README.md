# Musoff🎵

**EN**

**Musoff🎵** - is an application for listening to music, available on Windows and Android (with plans for iOS in the future). I’m an enthusiast who decided to break free from the "system"—simply because I want to listen to music.

Just a project I created—I got tired of paying for subscriptions and all that, so I released my own app for listening to music.  Please note: AI was used in the development of this application.

Это мой личный проект: мне надоело платить за подписки и всё в таком духе, поэтому я выпустил собственное приложение для прослушивания музыки. Обратите внимание: при разработке этого приложения использовался искусственный интеллект.
